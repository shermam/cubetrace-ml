# Glossary: the machine-learning terms of this series

[← 10 · Infrastructure](10-infrastructure.md) · [The pipeline](README.md)

Every machine-learning (ML) term the series uses, with its meaning *in this pipeline* and a link for going deeper. The links
are to Wikipedia and, for the most standard terms, to Google's
[Machine Learning Glossary](https://developers.google.com/machine-learning/glossary) (if a link lands on
the top of that page, its search box finds the entry). The domain terms of speedcubing are at the end.

| Term | Meaning here | Deeper |
|---|---|---|
| **ablation** | a run with one component removed or degraded (every other frame dropped; the gyro channels left out) to measure what that component contributes | [Wikipedia](https://en.wikipedia.org/wiki/Ablation_(artificial_intelligence)) |
| **accuracy** | the share of predictions that are right; used for the symbol at the matched onsets (84%) | [Wikipedia](https://en.wikipedia.org/wiki/Accuracy_and_precision#In_classification), [Google](https://developers.google.com/machine-learning/glossary#accuracy) |
| **activation function** (GELU, the Gaussian error linear unit) | a non-linear function applied element-wise between layers; without one a stack of linear layers would collapse into one. GELU is the smooth one used here | [Wikipedia](https://en.wikipedia.org/wiki/Activation_function), [GELU paper](https://arxiv.org/abs/1606.08415) |
| **Adam, AdamW** | the optimizer: gradient descent with a per-parameter adaptive step; AdamW adds weight decay properly | [Wikipedia](https://en.wikipedia.org/wiki/Stochastic_gradient_descent#Adam), [AdamW paper](https://arxiv.org/abs/1711.05101) |
| **attention, self-attention** | the operation at the heart of a transformer: every element of a sequence computes weights over all the others and gathers their vectors; the transformer body uses it over frames | [Wikipedia](https://en.wikipedia.org/wiki/Attention_(machine_learning)), [Google](https://developers.google.com/machine-learning/glossary#self-attention) |
| **augmentation** (data augmentation) | training on altered copies of the data so the model cannot memorize the originals; here time masking | [Wikipedia](https://en.wikipedia.org/wiki/Data_augmentation), [Google](https://developers.google.com/machine-learning/glossary#data-augmentation) |
| **backpropagation** | the algorithm that computes the gradient of the loss with respect to every parameter, layer by layer backwards; PyTorch does it automatically (`loss.backward()`) | [Wikipedia](https://en.wikipedia.org/wiki/Backpropagation), [Google](https://developers.google.com/machine-learning/glossary#backpropagation) |
| **baseline** | a deliberately simple system that a result must beat to mean anything; here the motion-peak baseline (WER 1.62) | [Google](https://developers.google.com/machine-learning/glossary#baseline) |
| **batch, batch size** | the group of examples (8 clips) that one forward and backward pass processes; the loss is averaged over it | [Google](https://developers.google.com/machine-learning/glossary#batch-size) |
| **bidirectional** (BiGRU) | a recurrent layer run forward and backward over the sequence, so each position sees both past and future | [Wikipedia](https://en.wikipedia.org/wiki/Bidirectional_recurrent_neural_networks) |
| **buffer** (PyTorch) | a tensor saved with the model but not trained; here the input normalization's mean and std | [PyTorch](https://pytorch.org/docs/stable/generated/torch.nn.Module.html#torch.nn.Module.register_buffer) |
| **calibration** (here) | a rotation between the gyro's frame and the camera's, one per attempt. Not the other ML sense (making predicted probabilities match observed frequencies) | page [09](09-orientation.md) |
| **checkpoint** | a saved snapshot of the model (parameters, buffers) and what an evaluation needs; `best.pt`, `last.pt` | [Google](https://developers.google.com/machine-learning/glossary#checkpoint) |
| **class, classification** | predicting one of a fixed set of categories; here 25 classes per frame ("no onset" and 24 symbols) | [Wikipedia](https://en.wikipedia.org/wiki/Statistical_classification), [Google](https://developers.google.com/machine-learning/glossary#classification-model) |
| **class imbalance, class weights** | when one class is far more frequent (about eight frames in nine are "no onset"); the loss weights the rare classes up so the model does not ignore them | [Google](https://developers.google.com/machine-learning/glossary#class-imbalanced-dataset) |
| **CLS token** | in a vision transformer, an extra token whose final vector summarizes the whole image; half of the DINOv2 feature | [ViT paper](https://arxiv.org/abs/2010.11929) |
| **CNN** (convolutional neural network) | a network of convolutions, the classic architecture for images; ResNet-18 is one | [Wikipedia](https://en.wikipedia.org/wiki/Convolutional_neural_network), [Google](https://developers.google.com/machine-learning/glossary#convolutional-neural-network) |
| **confusion matrix, confusions** | the counts of (true class, predicted class) pairs; here at the onsets matched on timing, grouped by kind of error | [Wikipedia](https://en.wikipedia.org/wiki/Confusion_matrix), [Google](https://developers.google.com/machine-learning/glossary#confusion-matrix) |
| **convolution** (1D) | a small learnt filter slid along the sequence; here over time, 5 frames wide | [Wikipedia](https://en.wikipedia.org/wiki/Convolutional_neural_network#Convolutional_layers) |
| **cross-entropy** | the loss for classification: minus the log of the probability given to the right class | [Wikipedia](https://en.wikipedia.org/wiki/Cross-entropy), [Google](https://developers.google.com/machine-learning/glossary#cross-entropy) |
| **CTC** (connectionist temporal classification) | a loss and decoding scheme for predicting a sequence from a longer sequence of frames without per-frame labels, with a blank symbol and a collapse rule | [Wikipedia](https://en.wikipedia.org/wiki/Connectionist_temporal_classification), [paper](https://www.cs.toronto.edu/~graves/icml_2006.pdf) |
| **CUDA, GPU** | NVIDIA's platform for running computation on a graphics processor; PyTorch's `device="cuda"` | [Wikipedia](https://en.wikipedia.org/wiki/CUDA) |
| **data leakage** | information from the test data reaching the training or the model selection, which inflates the test score; avoided by splitting by session and choosing the threshold on val | [Wikipedia](https://en.wikipedia.org/wiki/Leakage_(machine_learning)) |
| **decoding, decoder** | turning the model's per-frame probabilities into a discrete sequence; here peak picking or greedy CTC | page [07](07-decoding.md) |
| **dropout** | during training, zeroing each activation with some probability (0.2), a regularizer | [Wikipedia](https://en.wikipedia.org/wiki/Dilution_(neural_networks)), [Google](https://developers.google.com/machine-learning/glossary#dropout-regularization) |
| **early stopping, patience** | stopping training when the validation score has not improved for `patience` epochs, keeping the best epoch | [Wikipedia](https://en.wikipedia.org/wiki/Early_stopping), [Google](https://developers.google.com/machine-learning/glossary#early-stopping) |
| **edit distance** (Levenshtein) | the fewest substitutions, insertions and deletions between two sequences; the numerator of WER | [Wikipedia](https://en.wikipedia.org/wiki/Levenshtein_distance) |
| **embedding, feature vector** | a vector of numbers that represents an input (a frame) so that similar inputs are close; the encoder's 768 numbers | [Wikipedia](https://en.wikipedia.org/wiki/Feature_learning), [Google](https://developers.google.com/machine-learning/glossary#embedding-vector) |
| **encoder** (frozen) | the pretrained network that turns a frame into its feature vector; "frozen" means its weights are never changed here | page [03](03-features.md) |
| **epoch, step** | one pass over the training set; one batch's update | [Google](https://developers.google.com/machine-learning/glossary#epoch) |
| **F1, precision, recall, TP/FP/FN** | precision = right predictions / all predictions; recall = right predictions / all true events; F1 their harmonic mean; TP, FP, FN the matched, invented and missed events | [Wikipedia](https://en.wikipedia.org/wiki/F-score), [precision and recall](https://en.wikipedia.org/wiki/Precision_and_recall), [Google](https://developers.google.com/machine-learning/glossary#f1) |
| **feed-forward layer** | a small network applied to each position on its own (two linear layers with an activation between), the second half of every transformer layer | [Wikipedia](https://en.wikipedia.org/wiki/Feedforward_neural_network) |
| **feature, feature extraction** | an input variable of a model; extracting features means computing a compact representation (the encoder's vectors) from raw data (pixels) | [Wikipedia](https://en.wikipedia.org/wiki/Feature_(machine_learning)), [Google](https://developers.google.com/machine-learning/glossary#feature) |
| **fine-tuning** | continuing to train a pretrained network on new data; *not* done here (the encoder is frozen), a possible later step | [Wikipedia](https://en.wikipedia.org/wiki/Fine-tuning_(deep_learning)), [Google](https://developers.google.com/machine-learning/glossary#fine-tuning) |
| **fp16, fp32, mixed precision** | 16- and 32-bit floating point; running the encoder in fp16 on the GPU speeds it up at a precision the features do not miss | [Wikipedia](https://en.wikipedia.org/wiki/Half-precision_floating-point_format), [PyTorch AMP, automatic mixed precision](https://pytorch.org/docs/stable/amp.html) |
| **generalization** | doing well on data not trained on; the point of the val/test split and of regularization | [Wikipedia](https://en.wikipedia.org/wiki/Generalization_error), [Google](https://developers.google.com/machine-learning/glossary#generalization) |
| **gradient, gradient descent** | the direction in which the loss increases fastest; descent moves the parameters the other way by small steps | [Wikipedia](https://en.wikipedia.org/wiki/Gradient_descent), [Google](https://developers.google.com/machine-learning/glossary#gradient-descent) |
| **gradient clipping** | rescaling a too-large gradient before the step, against spikes | [Google](https://developers.google.com/machine-learning/glossary#gradient-clipping) |
| **ground truth, label, target** | the true answer the model is trained to produce; here derived from the cube's own move report | [Google](https://developers.google.com/machine-learning/glossary#ground-truth) |
| **GRU, RNN, hidden state** | a recurrent neural network reads a sequence one step at a time, carrying a hidden state; the gated recurrent unit is an RNN cell with learnt gates for updating that state | [Wikipedia](https://en.wikipedia.org/wiki/Gated_recurrent_unit), [RNN](https://en.wikipedia.org/wiki/Recurrent_neural_network), [paper](https://arxiv.org/abs/1406.1078) |
| **hyperparameter** | a setting chosen by the engineer rather than learnt: the width, the learning rate, the threshold; the TOML config holds them | [Wikipedia](https://en.wikipedia.org/wiki/Hyperparameter_(machine_learning)), [Google](https://developers.google.com/machine-learning/glossary#hyperparameter) |
| **ImageNet** | the large labelled image dataset the encoders' authors trained on (ResNet-18) or normalized for; its per-channel mean and std are the encoders' input normalization | [Wikipedia](https://en.wikipedia.org/wiki/ImageNet) |
| **inference** | running a trained model to get predictions, with no training | [Google](https://developers.google.com/machine-learning/glossary#inference) |
| **label smoothing, soft targets** | spreading a target's probability mass over neighbouring classes or frames instead of one hard answer; the optional `label_frames` | [paper](https://arxiv.org/abs/1512.00567) |
| **layer normalization** | renormalizing a layer's activations per example, which keeps training stable | [Wikipedia](https://en.wikipedia.org/wiki/Normalization_(machine_learning)), [paper](https://arxiv.org/abs/1607.06450) |
| **learning curve** | how the score changes with the amount or kind of training data; here the model trained on one recording session at a time, then on all | [Wikipedia](https://en.wikipedia.org/wiki/Learning_curve_(machine_learning)) |
| **learning rate, schedule** | the step size of gradient descent; the schedule changes it over training (a cosine from 1e-3 to 0) | [Wikipedia](https://en.wikipedia.org/wiki/Learning_rate), [Google](https://developers.google.com/machine-learning/glossary#learning-rate), [SGDR paper](https://arxiv.org/abs/1608.03983) |
| **logits, softmax** | the raw scores a network outputs per class; softmax turns them into probabilities that sum to 1 | [Wikipedia](https://en.wikipedia.org/wiki/Softmax_function), [Google](https://developers.google.com/machine-learning/glossary#logits) |
| **loss** | the number training minimizes: how wrong the model is on a batch | [Wikipedia](https://en.wikipedia.org/wiki/Loss_function), [Google](https://developers.google.com/machine-learning/glossary#loss) |
| **mask, padding** | clips of different lengths are padded to one length in a batch; the mask marks the real frames so the padding changes nothing | page [05](05-model.md) |
| **mean vs pooled** (metrics) | a split's metric as the average of per-clip values, or computed from the summed counts over all clips | page [08](08-evaluation.md) |
| **neural network, layer, parameter, weight, bias** | a function built from layers, each with adjustable numbers (weights and biases, the parameters) that training sets | [Wikipedia](https://en.wikipedia.org/wiki/Artificial_neural_network), [Google](https://developers.google.com/machine-learning/glossary#neural-network) |
| **normalization, standardization, z-score** | shifting and scaling inputs to mean 0 and standard deviation 1 per column, so every input has a comparable scale | [Wikipedia](https://en.wikipedia.org/wiki/Feature_scaling), [Google](https://developers.google.com/machine-learning/glossary#z-score-normalization) |
| **oracle** | a system given information it would not have in practice (here the solve's own labels to fit the rotation), as an upper bound | page [09](09-orientation.md) |
| **overfitting** | fitting the training data's particulars rather than the pattern, so the validation score worsens while the training loss improves | [Wikipedia](https://en.wikipedia.org/wiki/Overfitting), [Google](https://developers.google.com/machine-learning/glossary#overfitting) |
| **peak picking** | not ML: finding the local maxima of a signal above a threshold with a minimum spacing; the per-frame decoder | page [07](07-decoding.md) |
| **pooling** (global average pooling) | averaging a feature map over space to get one vector; ResNet-18's output | [Wikipedia](https://en.wikipedia.org/wiki/Convolutional_neural_network#Pooling) |
| **positional encoding** | the sinusoidal pattern added to a transformer's inputs so it knows the order of the frames | [Wikipedia](https://en.wikipedia.org/wiki/Transformer_(deep_learning_architecture)#Positional_encoding) |
| **pretrained, transfer learning** | a network trained by others on a large dataset, reused as is (frozen) or fine-tuned on a new task | [Wikipedia](https://en.wikipedia.org/wiki/Transfer_learning), [Google](https://developers.google.com/machine-learning/glossary#transfer-learning) |
| **quaternion, slerp, rotation matrix** | representations of a 3D rotation; slerp interpolates between two | [Wikipedia](https://en.wikipedia.org/wiki/Quaternions_and_spatial_rotation), [slerp](https://en.wikipedia.org/wiki/Slerp) |
| **regularization** | anything that discourages overfitting: dropout, weight decay, augmentation, early stopping | [Wikipedia](https://en.wikipedia.org/wiki/Regularization_(mathematics)), [Google](https://developers.google.com/machine-learning/glossary#regularization) |
| **residual connection** | adding a layer's input to its output, so the layer learns a correction and gradients have a shortcut; ResNet's idea, used in the convolutions here | [Wikipedia](https://en.wikipedia.org/wiki/Residual_neural_network) |
| **seed, determinism** | fixing the random generators so that a run can be repeated exactly | [Wikipedia](https://en.wikipedia.org/wiki/Random_seed), [PyTorch](https://pytorch.org/docs/stable/notes/randomness.html) |
| **self-supervised learning** | learning representations from unlabelled data by a pretext task (DINOv2: matching views of the same image) | [Wikipedia](https://en.wikipedia.org/wiki/Self-supervised_learning), [Google](https://developers.google.com/machine-learning/glossary#self-supervised-learning) |
| **sequence labelling** | predicting a label for every element of a sequence; the per-frame head | [Wikipedia](https://en.wikipedia.org/wiki/Sequence_labeling) |
| **Spearman's rank correlation** | a correlation on ranks rather than values; the gyro convention's check | [Wikipedia](https://en.wikipedia.org/wiki/Spearman%27s_rank_correlation_coefficient) |
| **supervised learning** | learning from (input, label) pairs; everything in `train` | [Wikipedia](https://en.wikipedia.org/wiki/Supervised_learning), [Google](https://developers.google.com/machine-learning/glossary#supervised-machine-learning) |
| **tensor** | an n-dimensional array; PyTorch's basic object (a batch is B × T × D) | [Wikipedia](https://en.wikipedia.org/wiki/Tensor_(machine_learning)) |
| **token, patch** | a unit of a transformer's input sequence; in a vision transformer, a 14 × 14-pixel patch of the image | [Google](https://developers.google.com/machine-learning/glossary#token) |
| **train / val / test split** | the three disjoint sets: to fit, to choose settings and stop, to report; here whole recording sessions | [Wikipedia](https://en.wikipedia.org/wiki/Training,_validation,_and_test_data_sets), [Google](https://developers.google.com/machine-learning/glossary#validation-set) |
| **transformer** | a network built from self-attention and feed-forward layers; the alternative body, and the architecture of the DINOv2 encoder | [Wikipedia](https://en.wikipedia.org/wiki/Transformer_(deep_learning_architecture)), [paper](https://arxiv.org/abs/1706.03762) |
| **vision transformer** (ViT) | a transformer over image patches; DINOv2 ViT-S/14 is a small one with 14-pixel patches | [Wikipedia](https://en.wikipedia.org/wiki/Vision_transformer), [paper](https://arxiv.org/abs/2010.11929) |
| **weight decay** | shrinking the weights a little at every step, a regularizer (AdamW's 0.01) | [AdamW paper](https://arxiv.org/abs/1711.05101) |
| **WER** (word error rate) | edit distance over the reference's length; the sequence metric, from speech recognition | [Wikipedia](https://en.wikipedia.org/wiki/Word_error_rate) |

## Domain terms

| Term | Meaning |
|---|---|
| **attempt, session, clip, segment** | one scramble + solve; one run of the app at the rig (hours, sometimes more than a day); one camera's recording of one segment; the scramble or the solve |
| **DNF** | did not finish: an attempt not solved |
| **facelets, Kociemba order** | the 54 stickers of a cube as a 54-letter string, in the order Herbert Kociemba's solver uses (U1–U9, R1–R9, F, D, L, B); the simulator's state |
| **lag** (`syncResidualMs`) | how far a camera's frames trail the cube's time, measured by the app's sync check |
| **onset** | the moment a move starts: its first quarter turn's time |
| **scramble, solve, inspection** | the prescribed moves that mix the cube; the solver's moves back to solved; the pause between them |
| **slice, double** | a middle-layer move (`M`, `S`, `E`), reported by the cube as two opposite face turns; a half turn (`R2`), reported as two quarter turns |
| **TPS** | turns per second, the attempt's speed |
| **WCA (World Cube Association) notation** | the standard move letters, `U R F D L B`, `'` and `2` ([the regulations](https://www.worldcubeassociation.org/regulations/#12a)) |
