# Record schemas

Copies of the JSON Schemas the capture app writes, taken from
[shermam/cubetrace](https://github.com/shermam/cubetrace) `packages/core/schema/` at commit 5dd2047
(2026-10-05): `attempt.schema.json`, `frames.schema.json`, `gyro.schema.json`, `session.schema.json`.
The app's `docs/DATA-MODEL.md` is the reference for their meaning. Refresh them with
`scripts/sync-schemas.sh <path to a cubetrace checkout>` and record the commit here.
